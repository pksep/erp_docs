# Шаблон ADR

Используйте этот шаблон для новых записей об архитектурных решениях.

```md
# [ADR-0000] Название решения

* **Status:** Proposed
* **Date:** YYYY-MM-DD
* **Members:** Имя участника
* **Tags:** #tag

## Контекст

Опишите проблему, ограничения и причины, по которым нужно принять решение.

## Варианты решения

### Вариант 1

* **Плюсы:**
  - ...
* **Минусы:**
  - ...

### Вариант 2

* **Плюсы:**
  - ...
* **Минусы:**
  - ...

## Решение

Укажите выбранный вариант и причины выбора.

## Последствия

Опишите ожидаемые изменения, риски и дальнейшие действия.

## Дополнительные материалы

- [Реестр решений](../REGISTRY)
```
