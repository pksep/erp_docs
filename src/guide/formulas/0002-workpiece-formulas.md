# Расчет массы заготовки: краткий гайд для пользователя

Этот раздел помогает понять, какую формулу выбрать для типа материала и что означает каждая переменная в расчете массы заготовки.

## Как это работает

1. Для типа материала выбирается формула расчета массы
2. Для нужных характеристик задается источник значения:
   - постоянное значение на материале
   - переменное значение на детали при выборе заготовки
3. Система подставляет значения в формулу и рассчитывает:
   - расчетную массу заготовки
   - отходы, если это предусмотрено логикой детали

## Обозначения в формулах

- `m` — масса заготовки, кг
- `ρ` — плотность материала, кг/м3
- `L` — длина заготовки, мм
- `B` — ширина заготовки, мм
- `H` — высота заготовки, мм
- `t` — толщина или толщина стенки, мм
- `D` — наружный диаметр, мм
- `S` — размер под ключ, мм
- `A` — площадь поперечного сечения, м2
- `q` — масса погонного метра, кг/м

## Формулы

### 1. Прямоугольная заготовка

Формула:

`m = ρ * L * B * H`

Расшифровка:

- `m` — масса заготовки, кг
- `ρ` — плотность материала, кг/м3
- `L` — длина заготовки, мм
- `B` — ширина заготовки, мм
- `H` — высота заготовки, мм

Что считает:

Массу прямоугольной заготовки по длине, ширине, высоте и плотности.

Подходит для:
- листа
- прямоугольной болванки
- заготовки, которая задается по габаритам
- случаев, когда изделие вырезается из прямоугольной заготовки

### 2. Прямоугольное сечение

Формула:

`m = ρ * L * B * t`

Расшифровка:
- `m` — масса заготовки, кг
- `ρ` — плотность материала, кг/м3
- `L` — длина заготовки, мм
- `B` — ширина заготовки, мм
- `t` — толщина или толщина стенки, мм

Что считает:

Массу заготовки с прямоугольным поперечным сечением.

Подходит для:

- листа
- полосы
- шпонки
- прямоугольного профиля

### 3. Полнотелое круглое сечение

Формула:

`m = ρ * π * D² / 4 * L`

Расшифровка:
- `m` — масса заготовки, кг
- `ρ` — плотность материала, кг/м3
- `D` — наружный диаметр, мм
- `L` — длина заготовки, мм

Что считает:

Массу полнотелой круглой заготовки по длине, диаметру и плотности.

Подходит для:

- круглого проката
- проволоки
- полнотелого штока

### 4. Полое круглое сечение

Формула:

`m = ρ * π * t * (D - t) * L`

Расшифровка:
- `m` — масса заготовки, кг
- `ρ` — плотность материала, кг/м3
- `t` — толщина стенки, мм
- `D` — наружный диаметр, мм
- `L` — длина заготовки, мм

Что считает:

Массу круглой трубы по наружному диаметру, толщине стенки, длине и плотности.

Подходит для:

- бесшовной трубы
- электросварной трубы
- хонингованной трубы
- круглого полого профиля

### 5. Полое профильное сечение

Формула:

`m = ρ * (B * H - (B - 2t) * (H - 2t)) * L`

Расшифровка:
- `m` — масса заготовки, кг
- `ρ` — плотность материала, кг/м3
- `B` — ширина заготовки, мм
- `H` — высота заготовки, мм
- `t` — толщина стенки, мм
- `L` — длина заготовки, мм

Что считает:

Массу профильной трубы по наружным размерам, толщине стенки, длине и плотности.

Подходит для:

- профильной трубы
- прямоугольной трубы
- квадратной трубы

### 6. Шестигранное сечение

Формула:

`m = ρ * (√3 / 2) * S² * L`

Расшифровка:
- `m` — масса заготовки, кг
- `ρ` — плотность материала, кг/м3
- `S` — размер под ключ, мм
- `L` — длина заготовки, мм

Что считает:

Массу шестигранного проката по размеру под ключ, длине и плотности.

Подходит для:

- шестигранника.

### 7. По площади сечения

Формула:

`m = ρ * A * L`

Расшифровка:
- `m` — масса заготовки, кг
- `ρ` — плотность материала, кг/м3
- `A` — площадь поперечного сечения, м2
- `L` — длина заготовки, мм

Что считает:

Массу заготовки по площади поперечного сечения, длине и плотности.

Подходит для:

- уголка
- швеллера
- сложного профиля, у которого известна площадь сечения

### 8. По массе погонного метра

Формула:

`m = q * L`

Расшифровка:
- `m` — масса заготовки, кг
- `q` — масса погонного метра, кг/м
- `L` — длина заготовки, мм

Что считает:

Массу заготовки по нормативной массе одного погонного метра и длине.

Подходит для:

- трубок
- шлангов
- материалов, для которых масса задается как кг/м
